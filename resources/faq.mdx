## General

<AccordionGroup>
  <Accordion title="What is Ora Browser?">
    Ora is a fast, secure, and beautiful browser built for macOS. Inspired by Safari and Arc, Ora delivers a clean, native experience that feels at home on macOS—without unnecessary bloat.

    Built with SwiftUI/AppKit and powered by WebKit, Ora focuses on privacy-first browsing with a native macOS interface.
  </Accordion>

  <Accordion title="Is Ora Browser ready for daily use?">
    <Warning>
    Not yet. Ora is currently in early stages of development and **not yet ready for day-to-day use**. A beta version with core functionalities will be released soon.
    </Warning>

    Check the [roadmap](/resources/roadmap) to see what features are being developed and when they'll be available.
  </Accordion>

  <Accordion title="What platforms does Ora support?">
    Ora Browser is built exclusively for macOS. The minimum supported version is **macOS 14.0 (Sonoma)** or later.

    Requirements:
    - macOS 14.0+
    - Apple Silicon or Intel processor
  </Accordion>

  <Accordion title="Is Ora Browser free?">
    Yes, Ora Browser is free and open source. It's licensed under the [GPL-2.0 license](/resources/license), which means you can use, modify, and distribute it freely.

    If you'd like to support development, consider [sponsoring the project](https://github.com/sponsors/the-ora) or [buying us a coffee](https://buymeacoffee.com/orabrowser).
  </Accordion>
</AccordionGroup>

## Features & Functionality

<AccordionGroup>
  <Accordion title="What are Spaces?">
    Spaces are isolated browsing containers that let you organize tabs by context. Each Space maintains separate:
    - Cookies
    - Local storage
    - Sessions

    This is perfect for separating work and personal browsing, or managing multiple accounts on the same website.
  </Accordion>

  <Accordion title="Does Ora support extensions?">
    Extension support is currently in development. The goal is to support both Safari and Chrome extensions.

    Progress: [#137](https://github.com/the-ora/browser/pull/137)

    This feature is planned for the Beta 1 release.
  </Accordion>

  <Accordion title="Does Ora have ad blocking?">
    Built-in ad blocking is planned but not yet implemented. Ora currently includes:
    - Privacy-first browsing
    - Content blocker for tracking prevention

    Full ad blocking functionality is on the roadmap for the Beta release.
  </Accordion>

  <Accordion title="Can I sync my data across devices?">
    Sync functionality is not yet implemented. This feature will be considered for future releases after the stable 1.0 version.
  </Accordion>

  <Accordion title="Does Ora support bookmarks?">
    Bookmark management with folders is planned for the Beta 1 release but not yet implemented.
  </Accordion>
</AccordionGroup>

## Development & Contributing

<AccordionGroup>
  <Accordion title="How can I contribute to Ora?">
    Contributions are welcome! To get started:

    1. Read the [Contributing Guide](/development/contributing)
    2. Check the [Code of Conduct](/resources/code-of-conduct)
    3. Join the [Discord community](https://discord.gg/9aZWH52Zjm)
    4. Browse [open issues](https://github.com/the-ora/browser/issues)

    All skill levels are welcome, from documentation to code contributions.
  </Accordion>

  <Accordion title="What technologies does Ora use?">
    Ora is built with:
    - **Swift 5.9+** - Programming language
    - **SwiftUI/AppKit** - Native macOS UI framework
    - **WebKit** - Browser engine
    - **Xcode 15+** - Development environment

    Additional tools:
    - XcodeGen - Project generation
    - SwiftFormat - Code formatting
    - SwiftLint - Coding standards
    - Sparkle - Automatic updates
  </Accordion>

  <Accordion title="Do I need to disclose AI assistance when contributing?">
    Yes. If you use any kind of AI assistance to contribute, this must be disclosed in your pull request, commit, or issue, including the extent to which AI assistance was used.

    See the [Contributing Guide](/development/contributing) for complete details on AI assistance disclosure requirements.
  </Accordion>

  <Accordion title="Does Ora support hot reloading?">
    Yes! Ora supports live UI hot reloading via [InjectionIII](https://github.com/johnno1962/InjectionIII), letting you see SwiftUI changes instantly without rebuilding.

    This is a Debug-only feature that has zero impact on Release builds. See the [Contributing Guide](/development/contributing) for setup instructions.
  </Accordion>
</AccordionGroup>

## Privacy & Security

<AccordionGroup>
  <Accordion title="How does Ora protect my privacy?">
    Ora is privacy-first by design:
    - Privacy-first browsing mode
    - Built-in content blocker for tracking prevention
    - Private browsing mode
    - No telemetry or tracking (beyond what WebKit requires)
    - Open source code that can be audited
  </Accordion>

  <Accordion title="Does Ora collect any data?">
    Ora does not collect or transmit user data. The browser is designed to respect your privacy completely.

    The only network requests made are:
    - Your normal browsing activity
    - Update checks (via Sparkle)
  </Accordion>

  <Accordion title="How are updates secured?">
    Ora uses Ed25519 cryptographic keys to sign and verify app updates for security. All updates are:
    - Cryptographically signed
    - Verified before installation
    - Delivered over secure connections

    See the [Security Guide](/resources/security) for technical details.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Where can I report bugs?">
    Report bugs on [GitHub Issues](https://github.com/the-ora/browser/issues) or [Discord](https://discord.gg/9aZWH52Zjm).

    Please include:
    - macOS version
    - Ora Browser version
    - Steps to reproduce
    - Expected vs actual behavior
    - Screenshots if applicable

    See the [Support page](/resources/support) for detailed guidelines.
  </Accordion>

  <Accordion title="The browser crashes on launch. What should I do?">
    Try these steps:

    1. Check that you're running macOS 14.0 or later
    2. Delete the app and download a fresh copy
    3. Check Console.app for crash logs
    4. Report the issue on GitHub with the crash log

    Since Ora is in early development, crashes may occur. Your bug reports help us improve stability.
  </Accordion>

  <Accordion title="How do I reset Ora to defaults?">
    To completely reset Ora:

    1. Quit Ora Browser
    2. Delete these directories:
       ```bash
       ~/Library/Application Support/Ora
       ~/Library/Caches/Ora
       ~/Library/Preferences/com.ora.browser.plist
       ```
    3. Relaunch Ora

    <Warning>
    This will delete all your browsing data, settings, and sessions.
    </Warning>
  </Accordion>
</AccordionGroup>
