# Welcome to Ora Browser

Ora is a fast, secure, and beautiful browser built for macOS. Inspired by Safari and Arc, Ora delivers a clean, native experience that feels at home on macOS—without unnecessary bloat.

<Note>
Ora is currently in early stages of development and **not yet ready for day-to-day use**. A beta version with core functionalities will be released soon.
</Note>

## Why Ora?

Ora Browser combines the best of modern web browsing with a privacy-first approach and native macOS design.

<CardGroup cols={2}>
  <Card title="Native macOS Experience" icon="apple">
    Built with SwiftUI and AppKit for a truly native macOS experience that feels right at home
  </Card>
  <Card title="Privacy First" icon="shield">
    Built-in content blocker for tracking prevention and ad blocking
  </Card>
  <Card title="Fast & Responsive" icon="bolt">
    Powered by WebKit for fast, efficient browsing

  <Card title="Clean Design" icon="sparkles">
    Beautiful, minimal interface focused on your content
  </Card>
</CardGroup>

## Key Features

<AccordionGroup>
  <Accordion title="Tabs & Spaces" icon="folder">
    Organize your browsing with vertical tabs, pinned tabs, and Spaces (tab containers) for grouping related tabs together.
  </Accordion>
  
  <Accordion title="Quick Launcher" icon="rocket">
    Instant navigation and search with the Quick Launcher—access any tab, search the web, or navigate to a URL in seconds.
  </Accordion>
  
  <Accordion title="Developer Mode" icon="code">
    Integrated developer tools for debugging and inspecting web pages.
  </Accordion>
  
  <Accordion title="Session Restore" icon="rotate-right">
    Never lose your browsing session—Ora automatically restores tabs after crashes or app restarts.
  </Accordion>
  
  <Accordion title="Picture-in-Picture" icon="video">
    Watch videos while browsing with native Picture-in-Picture support.
  </Accordion>
  
  <Accordion title="Private Browsing" icon="user-secret">
    Browse privately with dedicated private browsing windows.
  </Accordion>
</AccordionGroup>
